      https://github.com/frida/frida/releases
      
   b) Extract and deploy:
      xz -d frida-server-xx-android-arm64.xz
      adb connect 127.0.0.1:5555
      adb push frida-server /data/local/tmp/
      adb shell chmod +x /data/local/tmp/frida-server

      adb shell /data/local/tmp/frida-server -D

================================================================================
PART 3 TECHNICAL DETAILS
================================================================================

How the hooks work:

1. build_hook.js
   - Hooks into android.os.Build class
   - Replaces MODEL, BRAND, HARDWARE, FINGERPRINT properties
   - Hooks SystemProperties.get() for ro.* properties
   - Hides emulator properties before game sees them

2. qemu_hook.js
   - Hides "goldfish" and "ranchu" hardware identifiers
   - Sets ro.kernel.qemu to "0" (not an emulator)
   - Replaces generic/unknown device identifiers
   - Fixes fingerprint format

3. sensor_hook.js
   - Fakes SensorManager.getDefaultSensor()
   - Returns fake sensors based on profile configuration
   - Advanced mode: Hooks SensorManager.registerListener()

When injected:
1. All 3 hooks are combined into one JavaScript file
2. Device properties from selected profile are embedded
3. JavaScript is loaded into game process memory
4. Hooks intercept ALL property accesses
5. Game sees spoofed values as real properties
